◆ Key Judgments

01 We assess with high confidence that AI guardrails are not functioning as a meaningful barrier for adversarial use — Talos collected real artifact evidence this week showing most actors bypass restrictions with trivial natural-language claims. Actor skill level, not model restrictions, is the primary determinant of damage done.
02 We assess with high confidence that supply-chain attacks are accelerating in automation — this week alone: a self-propagating npm worm (keyv), a yearlong undetected trojanized VPN installer (QuickFox), a fake-update RMM campaign (SMOKE#SCREEN), and a 788-package typosquatting RAT campaign (WEL1DROPPER). Each exploited trust in legitimate software delivery.
03 We assess with high confidence that identity-layer attacks are outpacing defenses — Pass-ta-key confirms synced passkeys are exploitable in practice (not just theoretically); token jacking confirms stolen API keys enter gray-market resale within minutes of theft. Hardware FIDO2 keys remain the single control that blocks most of these paths.
04 We assess with high confidence that "first patch didn't hold" is a recurring pattern — N-central's CVE-2026-18556→18577 bypass is this week's primary example. Treat any vendor's "patched" status as provisional until a second review confirms no bypass route remains.
05 We assess with moderate confidence that BI and data platforms are now a preferred entry point for credential pivoting — Metabase's CVSS 10.0 zero-day is the immediate example, but the pattern (BI tools holding privileged credentials to multiple production databases simultaneously) means a single unauthenticated compromise cascades into an organization's entire data estate.
06 We assess with moderate confidence that AI coding agent automation workflows are a maturing attack surface — CVE-2026-54316 (Claude Code) and the CVSS 10.0 Gemini CLI flaw both demonstrated that a public GitHub issue with no repository permissions can compromise a CI runner and steal workflow credentials. Standard interactive AI coding use is not the risk; automated issue-processing pipelines are.
